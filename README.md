# Global Trade Web 🌍

Sitio web en inglés dedicado al **comercio internacional**. Su objetivo es acercar a empresas y emprendedores información, recursos y contacto para operar en mercados globales.

## Descripción

La web presenta de forma clara y accesible los servicios y contenidos relacionados con la exportación e importación: mercados, documentación, logística y contacto. Todo el contenido del sitio está redactado en **inglés** para llegar a una audiencia internacional.

## Secciones principales

- **Home**: presentación general del proyecto.
- **About Us**: quiénes somos y nuestra misión.
- **Services**: servicios de comercio internacional.
- **Markets**: información sobre mercados y países.
- **Contact**: formulario y datos de contacto.

> Ajusta las secciones a las que tenga realmente vuestra web.
